📊 Student Marks Analysis

📌 About the Project

This is a beginner-friendly Python project that analyzes student marks in different subjects, including Python, SQL, and Maths.

🎯 Features

- Displays student names and marks.
- Calculates total marks.
- Calculates average marks.
- Helps compare student performance.

🛠️ Technologies Used

- Python
- Lists
- Dictionaries
- Loops
- Basic calculations

💻 Sample Students

The project uses student data containing names and marks in Python, SQL, and Maths.

🚀 How to Run

1. Download or clone this repository.
2. Open the project in VS Code.
3. Run the following command:

python student_analysis.py

📚 What I Learned

- Working with lists and dictionaries.
- Performing calculations using Python.
- Organizing and analyzing student data.
